
# 3D Joint Gravity-Magnetic Inversion Framework

## Overview

This repository contains a physics-informed 3D joint gravity and magnetic inversion framework for subsurface geological modeling.

The workflow integrates:

- Gravity observations
- Magnetic observations
- Physics-based forward modeling
- Neural network inversion
- Well-log constraints
- Structural geology interpretation
- 3D visualization

## Main Capabilities

### Geophysical Modeling

- Joint gravity inversion
- Magnetic susceptibility inversion
- DEM-aware modeling
- Physics-informed constraints

- Physics-informed U-Net architecture
- Constraint-based optimization
- Smoothness regularization


### Structural Geology

- Fault surface extraction
- Candidate structural surfaces
- Ridge interpretation
- 3D geological rendering


### Validation

- Well-log comparison
- Density validation
- Susceptibility validation
- Seismic integration support
